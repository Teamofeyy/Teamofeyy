## What I build

- **Backend and network services** with Rust, Tokio, Axum, Tower HTTP and gRPC
- **Protocol-level integrations** over TCP/IP and Unix domain sockets
- **Data-backed services** using PostgreSQL
- **Terminal interfaces** with Ratatui
- **Reproducible infrastructure** with Nix, NixOS, system flakes and CI/CD
- **Deployments for servers and distributed agents**, managed declaratively through Nix
- **Reverse-proxy and container setups** with Caddy, Nginx and Docker

## Open source

### [fast-webp](https://github.com/Teamofeyy/fast-webp)

A focused WebP encoder for Rust applications that need a short, fast path from image buffers or proxy payloads to WebP through `libwebp-sys`.

Practical Rust workflow snippets for the Zed editor, designed to remove repetitive setup and keep common development actions close at hand.

### [Nixpkgs contribution: Look](https://github.com/NixOS/nixpkgs/pull/554287)

Packaging and validation work for bringing the Rust/Tauri launcher Look to Nixpkgs, including dependency cleanup, reproducible builds and maintainer integration.
